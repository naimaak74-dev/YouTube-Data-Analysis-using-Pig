# YouTube Data Analysis Using Apache Pig

This project performs data analysis on the YouTube dataset using Apache Pig and Hadoop.

## Analyses

1. Top 10 Rated Videos
2. Top 10 Categories
3. Top 10 Rated Videos by Category
4. Top 10 Viewed Videos
5. Top 10 Viewed Videos by Category

## Technologies Used

- Apache Hadoop
- Apache Pig
- HDFS
- Windows
- YouTube Dataset

## Dataset

The project uses the YouTube 0222 dataset.

The original dataset is not included in this repository because of its large file size.

## Pig Scripts

All Pig scripts are available in the `scripts` folder.

## Output

The generated analysis results are available in the `output` folder.
